# Task Manager Web App

A simple web application for managing daily tasks.

## Features
- Login (demo account: `demo` / `demo123`)
- Add a task
- Mark a task as completed
- Delete a task
- Task counter
- Logout

## How to run
```
npm start
```
Then open http://localhost:3000

No extra installs are needed. The app uses plain HTML, CSS, and JavaScript, with a small Node.js server.
